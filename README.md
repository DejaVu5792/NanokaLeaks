# NanokaLeaks
Quick VIBE CODED python script to quickly view newest characters in games tracked by [nanoka](https://nanoka.cc/)

## Installation
### Using [bin](https://github.com/marcosnils/bin)
```bash
bin install https://github.com/DejaVu5792/NanokaLeaks
```
### Using [AppMan](https://github.com/ivan-hc/AppMan)
```bash
appman -e DejaVu5792/NanokaLeaks nanokaleaks
```

## Building
Run `just build` for the onefile binary or `just appimage` for the self-updating AppImage. See [BUILDING.md](BUILDING.md) for prerequisites, build internals, CI, release steps, and troubleshooting.
